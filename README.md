# Free Config

تجمیع کانفیگ‌های عمومی از منابع معرفی‌شده گیت‌هاب، کانال تلگرام و OpenProxyList؛ بدون نیاز به سرور جداگانه برای لینک اشتراک.

## لینک‌های ثابت

- **اشتراک Base64 برای برنامه‌های سازگار:** https://raw.githubusercontent.com/mahxray/Free-Config/main/base64.txt
- **فهرست متنی کانفیگ‌ها:** https://raw.githubusercontent.com/mahxray/Free-Config/main/configs.txt
- [وضعیت دریافت و تعداد کانفیگ هر منبع](status.json)
- [فهرست منابع](sources.json)
- [اجرای خودکار و دستی](https://github.com/mahxray/Free-Config/actions/workflows/update.yml)

همه ۲۸ منبع معرفی‌شده ثبت شده‌اند: ۲۵ مخزن گیت‌هاب، کانال `v2ray_free_config_iran`، OpenProxyList و فایل Patterniha. `whitedns-sub` تکراری حذف شده است. خروجی هر منبع نیز در `data/sources/` نگهداری می‌شود و مسیر آن در گزارش وضعیت آمده است. منابع ناموجود یا ناموفق در گزارش با خطا مشخص می‌شوند؛ ثبت منبع به معنی دریافت موفق از آن نیست.

## به‌روزرسانی

GitHub Actions برای اجرای ساعتی در دقیقه ۱۷ تنظیم شده است؛ اجرای دستی از **Actions → Update public configs → Run workflow** نیز ممکن است. زمان‌بندی GitHub ممکن است تأخیر داشته باشد. این کار به توکن شخصی یا توکن تلگرام نیاز ندارد و از توکن داخلی GitHub Actions استفاده می‌کند. فایل `sources.json` را برای تغییر منابع ویرایش کنید.

اجرای محلی با Python 3.10 یا بالاتر و بدون بسته اضافی:

```bash
python -m unittest discover -s tests -v
python collect.py
```

در صورت نیاز به سهمیه بیشتر GitHub API، متغیر محیطی `GITHUB_TOKEN` را تنظیم کنید؛ این مقدار فقط برای درخواست‌های API گیت‌هاب ارسال می‌شود و در فایل خروجی نوشته نمی‌شود.

## محدوده دریافت

فایل‌های متن ساده و اشتراک Base64 با URIهای VLESS، VMess، Trojan، Shadowsocks، SSR، Hysteria، Hysteria2 و TUIC خوانده می‌شوند. تبدیل Clash YAML یا Xray JSON انجام نمی‌شود. برای هر مخزن تا ۲۰۰ فایل متنی احتمالی، هر پاسخ تا ۲ مگابایت و هر منبع تا ۵۰هزار کانفیگ خوانده می‌شود. خروجی اصلی حداکثر ۲۰۰هزار کانفیگ و ۳۲ مگابایت متن است؛ دریافت ناقص و رسیدن به محدودیت در `status.json` مشخص می‌شود. این محدودیت‌ها مانع جمع‌آوری نامحدود تمام گیت‌هاب می‌شوند.

تلگرام از نمای عمومی وب خوانده می‌شود؛ آرشیو کامل، کانال خصوصی و فایل‌های پیوست دریافت نمی‌شوند. کانفیگ‌های تکراری حذف می‌شوند؛ کانفیگ‌ها از نظر اتصال یا سرعت تست نمی‌شوند. در شکست دریافت یک منبع، آخرین خروجی موفق همان منبع حفظ می‌شود و `retained_previous` در گزارش فعال می‌شود. کد هیچ مخزن منبع اجرا نمی‌شود.

کانفیگ‌ها متعلق به منتشرکنندگان اصلی هستند و عمومی بودن آنها تضمین اتصال، امنیت یا دسترسی دائمی نیست.
